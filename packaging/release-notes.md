## Download and run DR-TBAtlas on your computer

No installation, Python or command line needed. Download the file for your
system from **Assets** below, then:

### Windows — `DR-TBAtlas-…-windows-x64.zip`

1. Right-click the downloaded file → **Extract All…**
2. Open the extracted `DR-TBAtlas` folder and double-click **DR-TBAtlas.exe**.
3. If Windows shows "Windows protected your PC", click **More info → Run anyway**.

### macOS — `…-macos-arm64.zip` (Apple silicon, M1 or later) or `…-macos-x64.zip` (Intel)

1. Double-click the downloaded file to unzip it, and drag **DR-TBAtlas** into
   your Applications folder.
2. Double-click **DR-TBAtlas**. The first time, macOS says it cannot verify
   the developer: click **Done**, open **System Settings → Privacy &
   Security**, scroll down and click **Open Anyway** next to DR-TBAtlas.

### Linux — `DR-TBAtlas-…-linux-x64.tar.gz`

Extract the archive and run `DR-TBAtlas/DR-TBAtlas`.

---

A small DR-TBAtlas window opens and the explorer appears in your web browser.
The first start takes a little longer while the genome browser tracks are
prepared. Keep the small window open while you work, and click **Quit** in it
when you are done.

Everything runs on your own computer; an internet connection is only needed
for the page styling and external links.
